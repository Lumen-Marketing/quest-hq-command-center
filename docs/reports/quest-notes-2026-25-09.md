Questbase Notes
Issues / Items to Address
•	Task Page Access
Workers currently cannot access the Task page when they land on Questbase.
•	Activity Log Visibility
Activity logs generated by other users are not displayed properly. Currently, only the Admin and Workspace Owner can see the activity logs.
•	File Upload Limit
The current file upload limit is 25 MB, but some files that need to be uploaded exceed this limit.
The 25 MB limit was implemented because the current Supabase project is using the Free Plan, which has limited storage capacity.
•	Multiple Category Selection
Category chips should allow users to select more than one category.
Example: A Project Type field should support multiple selections when needed.

Sales Role Permissions
Permissions Currently Enabled
[✓] View Workspace Apps
Allows the user to view and access the apps available within the workspace.
[✓] Create/Edit Workspace Apps
Allows the user to create and edit workspace apps.
During investigation, this permission was found to control several additional functions:
•	Allows the user to manage app settings.
•	Is responsible for saving/recording activity logs.
•	Allows the user to edit record fields.
•	Allows the user to add custom fields.
•	Allows the user to add additional options to category fields.
There is currently an issue with this permission because it controls functions beyond simply creating and editing apps.
For example, when this permission is disabled, activities performed by users without the permission are not recorded in the activity log. This means activity tracking is currently tied to the Create/Edit Workspace Apps permission.
Recommendation:
Consider adding a separate Track User Activity or View User Activity permission so that activity logging can be managed independently from app creation/editing.
The field-management functionality may also need to be separated into its own permission if users should be able to modify fields without having full app-editing access.
[✓] View App Records
Allows the user to view records within workspace apps.
[✓] Add App Records
Allows the user to create and add new records.
[✓] Edit App Records
Allows the user to edit existing records.
[✓] Delete App Records
Allows the user to delete records.
[✓] Export App Records
Allows the user to export the app record list as a CSV file.
[✓] Import App Records
Allows the user to import records into an app using a CSV file.
The CSV file must match the current app's configured record fields. The field structure/columns in the CSV must correspond to the fields available in the app for the import to work correctly.

Permissions Not Currently Enabled
[✗] Manage Workspace Settings
The Sales role currently does not have permission to manage workspace settings.
However, this permission needs to be reviewed because Create/Edit Workspace Apps currently also provides access to certain app settings.
Recommendation:
Separate workspace-level settings from app-level settings.
For example:
•	Manage Workspace Settings — Controls settings that affect the entire workspace.
•	Manage App Settings — Controls settings specific to an individual app.
•	Create/Edit Workspace Apps — Only controls the creation and editing of apps.
This would make the permission structure more granular and prevent one permission from unintentionally granting access to unrelated functionality.
